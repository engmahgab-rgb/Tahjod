# Tahjod v2
A focused Quran revision tracker.

- No memorization module.
- Daily Rub' plan.
- Completion button records exact date/time.
- Separate daily completion % and whole-Quran coverage %.
- 240 Rub' Quran coverage.
- Full completion cycle history.
- Next-day plan preparation after Isha.
- PWA/offline shell.
- No Quran text is embedded.
