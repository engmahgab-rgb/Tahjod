# Tahjod v3

Focused after-Isha Quran revision tracker.

## Features
- No memorization module.
- Sequential Rub' revision after Isha.
- Complete button records exact device date/time.
- Whole-Quran progress: unique completed Rub' / 240.
- Tonight's completed count.
- Current and next Rub'.
- Full revision history.
- 100% Quran cycle completion timestamp and preserved cycle history.
- JSON backup and restore.
- Backup file can be saved to Google Drive using the phone's Share/Save flow.
- Local offline storage and PWA cache.
- No Quran text is embedded.

## Important backup note
Browser local storage can be lost if browser/app data is cleared. Create backups regularly and save the JSON file in Google Drive.
